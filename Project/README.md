# ATmega128 임베디드 시스템 설계 프로젝트

> **과목**: 하이테크 (한국폴리텍대학교)
> **보드**: PAMS-AEB V9.1 (ATmega128 기반)
> **형태**: 개인 프로젝트 | **기간**: 5주

---

## 프로젝트 구조 (7단계 Stage-Gate)

| Stage | 단계 | 핵심 산출물 |
|-------|------|------------|
| ① | 주제 정의 | 프로젝트 제안서, 기능 목록표, 구현 가능성 검토표 |
| ② | 요구사항 정의 | 요구사항 정의서, 입출력 정의표, 동작 시나리오 |
| ③ | 시스템 설계 | 블록도, 동작 흐름도, 상태 전이도 |
| ④ | 회로 설계 | 핀맵, 회로도, 부품 목록표, 회로 검토표 |
| ⑤ | 펌웨어 구현 | 코드 구조 설명서, 모듈별 단위 테스트 |
| ⑥ | 테스트·디버깅 | 테스트 계획서, 테스트 결과표, 오류 기록표 |
| ⑦ | 시연·보고 | 최종 보고서, 발표자료, 최종 검증표 |

## 사용 방법

1. 각 Stage 양식 파일을 복사하여 본인 프로젝트 폴더에 보관
2. 각 단계 완료 후 **Gate 자가 점검 체크리스트** 확인
3. 모든 파일은 `[학번]_[이름]_하이테크프로젝트/` 폴더에 통합 관리
