아래는 지금 기준 코드에 **PC4 LED + 4자리 주사위 포커(보통 버전)** 을 얹은 미니 프로젝트 과제 설명입니다.

***

## 미니 프로젝트: 4자리 주사위 포커 & LED 패턴

### 1. 프로젝트 개요

- 사용 MCU: ATmega128  
- 사용 부품: 4-digit FND, 택트 스위치 2개(기존), LED 1개(신규, PC4)  
- 제공 코드:  
  - 0~9999 업카운터  
  - sw1(PC0): Start/Pause 토글  
  - sw2(PC1): Reset & Pause  
  - FND는 0.1초마다 1씩 증가하며 숫자 표시  

학생들은 이 코드를 **“4자리 주사위 포커 게임”** 으로 변형하고, **결과에 따라 LED를 다른 패턴으로 점멸**시키는 기능을 추가합니다.

***

### 2. 동작 요구사항

#### 2-1. 기본 카운터 → 4자리 주사위로 변경

1. 카운트 범위는 0~9999 대신 **각 자리가 1~6 사이의 “주사위 눈”** 이 되도록 변경합니다.  
   - 즉, FND의 네 자리는 항상 1~6 범위의 숫자만 표시됩니다.  
2. sw1(PC0) 버튼 동작을 다음과 같이 변경합니다.  
   - sw1을 **누르고 있는 동안** 현재 선택된 자릿수의 숫자가 1~6 범위에서 계속 변하도록 합니다.  
   - sw1을 **떼는 순간** 현재 자릿수의 숫자를 “확정”시키고, 다음 자릿수로 이동합니다.  
3. sw1을 네 번 사용하여 **4자리 모두 확정**하면, 더 이상 숫자는 변하지 않고, 아래의 “포커 족보 판정 + LED 패턴”으로 넘어갑니다.  
4. sw2(PC1)를 누르면  
   - 4자리 숫자와 내부 상태(현재 자리, 상태 플래그 등)를 모두 초기화하고  
   - 다시 처음 자리(천의 자리)부터 입력을 시작할 수 있도록 합니다.  

(※ 기존의 `count` 증가 로직은 필요에 맞게 수정하거나 제거해도 됩니다. 핵심은 **네 자리 각각을 1~6으로 뽑는 구조**를 만드는 것입니다.)

***

#### 2-2. 4자리 포커 족보 판정

4자리 숫자를 a, b, c, d (각각 1~6)라고 할 때, 다음 네 가지 패턴을 판정합니다.

1. **4개 일치 (Four of a Kind)**  
   - 예: 3 3 3 3  
2. **3개 일치 (Three of a Kind)**  
   - 예: 2 2 2 5  
3. **2개 일치 (One Pair)**  
   - 예: 6 6 2 3 (같은 숫자 2개만 있고, 나머지 2개는 서로도 다름)  
4. **2개 2개 일치 (Two Pairs)**  
   - 예: 4 4 1 1 (2개 + 2개, 숫자 2종류)  
5. 위 네 가지에 해당하지 않으면 **모두 다른 숫자 (No Hand)** 로 간주합니다.  

※ 구현 시에는 네 자리 값을 저장하는 변수(d0, d1, d2, d3 혹은 배열)를 사용하여, if 문 또는 간단한 카운트 로직으로 족보를 판정합니다.

***

### 3. LED 패턴 요구사항 (PC4)

PC4에 LED를 하나 연결하고, 4자리 입력이 완료되면 **족보에 따라 서로 다른 패턴으로 점멸**되도록 합니다.

패턴 표기에서:

- `-` : LED ON 상태 유지
- `_` 또는 공백 : LED OFF 상태 유지

아래 표기는 **개념적인 예시 패턴**입니다.  
(실제 시간은 `delay_ms()` 값으로 조절합니다.)

#### 3-1. 4개 일치 (Four of a Kind)

패턴:  
`- - - -  ____  - - - -  ____`  

예시 구현 (의미):
- ON 4번 (짧은 on/off 반복)  
- OFF 구간  
- 다시 ON 4번  
- 다시 OFF  

=> **가장 화려하고 빠르게 깜빡이는 패턴**으로 표현 (예: 짧은 딜레이로 8회 점멸 등)

#### 3-2. 3개 일치 (Three of a Kind)

패턴:  
`- - -  ____  - - -  ____`  

예시 구현:
- ON 3번
- 비교적 긴 OFF
- 다시 ON 3번
- 다시 긴 OFF  

=> **4개 일치보다 조금 덜 화려하지만, 여전히 눈에 띄는 패턴**

#### 3-3. 2개 일치 (One Pair)

패턴:  
`- -  ____  - -  ____`  

예시 구현:
- ON 2번
- 긴 OFF
- 다시 ON 2번
- 다시 긴 OFF  

=> **간단한 당첨 느낌**, 비교적 느리고 적은 횟수로 점멸

#### 3-4. 2개 2개 일치 (Two Pairs)

패턴:  
`- -  ____  - -  ______________ - -  ____  - -  ______________`  

예시 구현:
- ON 2번 → 짧은 OFF → ON 2번 → 긴 OFF → ON 2번 → 짧은 OFF → ON 2번 → 긴 OFF  
- 혹은 “두 쌍”을 느낄 수 있도록 **2번씩 묶어서 여러 차례 점멸**시키는 구조  

#### 3-5. 그 외 (모두 다른 숫자, No Hand)

- LED는 계속 OFF 상태 유지 (점등/점멸 없음)

### 4. 구현 조건 및 힌트

1. **포트 설정**  
   - 기존 코드에 더해 `DDRC`의 PC4를 출력으로 설정하고, 해당 핀으로 LED 제어  
   - 예: `DDRC |= (1 << PC4);`  

2. **LED 제어 함수 (권장)**  
   - LED 점멸 패턴 코드는 중복되기 쉬우므로,  
     - `void blink_led_pattern(uint8_t hand_type);`  
     와 같이 족보 타입에 따라 다른 패턴을 실행하는 함수를 만드는 것을 권장합니다.  

3. **게임 흐름 상태 변수**  
   - “현재 몇 번째 자리 입력 중인지”를 나타내는 변수(0~3)  
   - “4자리 입력이 끝났는지”를 나타내는 플래그 (예: `is_done`)  
   - “LED 패턴 실행 중인지” 여부는 FND 표시와 상관없이 동작하도록 해도 되고,  
     패턴 실행이 끝난 뒤에만 다시 reset 가능하도록 해도 됩니다.  

4. **버튼 디바운싱과 엣지 감지**  
   - 제공된 코드의 버튼 처리 로직(이전 상태/현재 상태 비교 + 20ms 딜레이)을 그대로 활용하면 됩니다.
