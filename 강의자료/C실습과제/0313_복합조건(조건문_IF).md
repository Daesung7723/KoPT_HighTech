# [미니 프로젝트] 복합 조건문을 활용한 스마트 입장 시스템

## 단순한 나이 제한을 넘어, 시간대, 회원 여부, 신체 조건 등을 모두 고려하여 입장료와 '우선탑승권(Magic Pass)' 발급 여부를 결정하는 프로그램을 작성합니다.

### 1. 프로그램 시나리오

> 당신은 대형 테마파크의 입장 시스템 개발자입니다. 고객의 나이, 입장 시간, 회원 여부, 그리고 특정 놀이기구 이용을 위한 키를 입력받아 최적의 요금과 혜택을 계산해야 합니다.


### 2. 비즈니스 로직 (요금 및 혜택 기준)

#### [A. 입장료 판정]

- 무료 입장: 3세 미만 이거나 70세 이상인 경우.
- 야간 할인: 입장 시간이 17시(오후 5시) 이후라면 나이에 상관없이 일괄 10,000원. (단, 무료 입장 대상자는 그대로 0원)
- 청소년 할인: 13세 이상 18세 이하이면서 '우대권(Membership)'이 있는 경우 50% 할인 (정가 40,000원 -> 20,000원).
- 일반 요금: 그 외 모든 경우 정가 40,000원.

#### [B. 우선탑승권(Magic Pass) 발급]

다음 조건 중 하나라도 충족하면 발급 가능 (True):
- '우대권(Membership)' 보유자이면서 키가 150cm 이상인 경우.
- 나이가 8세 미만이거나 65세 이상인 '교통 약자'인 경우.
- 입장 시간이 10시 이전인 '얼리버드' 방문객.

### 3. 프로그래밍 요구 사항

- age(int), height(int), time(int), is_member(int, 0 또는 1) 변수를 사용하세요.
-  && (AND), || (OR), ! (NOT) 연산자를 적절히 섞어서 한 줄의 조건식으로 표현해 보세요.
- 중첩 if문을 사용하여 '무료 입장'과 '야간 할인'의 우선순위를 해결하세요.

## [학습 목표]
여러 개의 조건을 조합할 때의 연산자 우선순위 이해.
> if - else if - else의 배타적 성격 파악.


# 정답 코드

```c
#include <stdio.h>

int main() {
    int age, height, time, is_member;
    
    printf("=== 스마트 입장 시스템 ===\n");
    printf("나이 입력: ");
    scanf("%d", &age);
    printf("키(cm) 입력: ");
    scanf("%d", &height);
    printf("입장 시간(0~23) 입력: ");
    scanf("%d", &time);
    printf("우대권 보유 여부 (1=있음, 0=없음): ");
    scanf("%d", &is_member);
    
    // ─── A. 입장료 판정 ───────────────────────────────────────────────
    int fee;
    
    // 우선순위 1: 무료 입장 (3세 미만 또는 70세 이상)
    if (age < 3 || age >= 70) {
        fee = 0;
    }
    // 우선순위 2: 야간 할인 (17시 이후 → 일괄 10,000원)
    else if (time >= 17) {
        fee = 10000;
    }
    // 우선순위 3: 청소년 회원 할인 (13세 이상 18세 이하 && 우대권 보유 → 50% 할인)
    else if ((age >= 13 && age <= 18) && is_member == 1) {
        fee = 20000;
    }
    // 우선순위 4: 일반 요금
    else {
        fee = 40000;
    }
    
    // ─── B. 우선탑승권(Magic Pass) 발급 판정 ─────────────────────────
    // 조건 1: 우대권 보유자이면서 키 150cm 이상
    // 조건 2: 나이 8세 미만이거나 65세 이상인 교통 약자
    // 조건 3: 입장 시간이 10시 이전인 얼리버드
    int magic_pass = (is_member == 1 && height >= 150) ||
                     (age < 8 || age >= 65) ||
                     (time < 10);
    
    // ─── 결과 출력 ────────────────────────────────────────────────────
    printf("\n========== 입장 결과 ==========\n");
    printf("입력 정보: 나이=%d세, 키=%dcm, 시간=%d시, 우대권=%s\n",
           age, height, time, is_member ? "있음" : "없음");
    printf("--------------------------------\n");
    
    if (fee == 0)
        printf("입장료    : 무료 (0원)\n");
    else
        printf("입장료    : %d원\n", fee);
    
    printf("Magic Pass: %s\n", magic_pass ? "✔ 발급" : "✘ 미발급");
    printf("================================\n");
    
    return 0;
}
```

---

## 코드 해설

### A. 입장료 — `if-else if-else` 우선순위 구조
```c
age < 3 || age >= 70   →  fee = 0          ← 최우선 (무료)
time >= 17             →  fee = 10,000     ← 2순위  (야간)
(13≤age≤18)&&member   →  fee = 20,000     ← 3순위  (청소년 회원)
else                   →  fee = 40,000     ← 기본   (일반)

if-else if-else 체인의 배타적 성격 덕분에 위 조건이 한번 참이 되면 아래 분기는 검사하지 않습니다. 
이것이 if를 여러 개 따로 쓰는 것과 핵심적으로 다른 점입니다.
```

B. Magic Pass — 한 줄 복합 조건식
```c
int magic_pass = (is_member == 1 && height >= 150)  // AND로 두 조건 묶기
              || (age < 8 || age >= 65)              // OR로 교통약자 표현
              || (time < 10);                        // 얼리버드
```

| 연산자 | 역할 | 우선순위 |
|--------|------|----------|
| `&&` | 둘 다 참이어야 성립 | `\|\|` 보다 높음 |
| `\|\|` | 하나만 참이면 성립 | `&&` 보다 낮음 |
| `!` | 논리 반전 | 가장 높음 |

`&&`가 `\|\|`보다 먼저 묶이므로, **괄호 없이도** 첫 번째 조건(`member AND height`)이 의도대로 평가됩니다. 괄호는 가독성을 위해 명시적으로 추가했습니다.

### 실행 예시
```c
나이=15, 키=160cm, 시간=9시, 우대권=있음

```
