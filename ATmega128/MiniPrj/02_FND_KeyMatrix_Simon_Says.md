# 미니 프로젝트 안내문
## ATmega128 사이먼 세즈(Simon Says) 게임

***

## 1. 프로젝트 개요

본 미니 프로젝트는 4×4 키 매트릭스와 4-digit FND를 활용하여  
**사이먼 세즈(Simon Says) 숫자 기억력 게임**을 직접 설계하고 구현하는 과제입니다.

시스템이 숫자 시퀀스를 FND에 순서대로 보여주면, 학생은 동일한 순서로 키패드를 통해  
숫자를 입력해야 합니다. 라운드가 진행될수록 시퀀스의 길이가 1씩 증가합니다.

***

## 2. 학습 목표

- 배열과 포인터를 활용한 시퀀스 데이터 관리
- FND 동적 구동(멀티플렉싱) 원리 응용
- 4×4 키 매트릭스 스캔 및 입력 처리
- 외부 LED 포트 제어

***

## 3. 게임 규칙

### 3.1 기본 동작

1. 전원을 켜면 FND에 레벨 선택 화면이 표시됩니다.
2. 키패드 `1`, `2`, `3` 중 하나를 눌러 난이도를 선택합니다.
3. 게임이 시작되면 시스템이 숫자 시퀀스를 FND에 순서대로 표시합니다.
4. 시퀀스 표시가 끝나면 같은 순서로 숫자를 입력합니다.
5. 모두 올바르게 입력하면 라운드가 클리어되고 시퀀스 길이가 1 증가합니다.
6. 틀린 숫자를 입력하면 라이프가 1개 감소하고, 해당 라운드 시퀀스를 다시 보여줍니다.
7. 라이프가 모두 소진되면 게임 오버입니다.
8. 게임 오버 후 최종 라운드와 점수를 순서대로 표시한 뒤 레벨 선택 화면으로 돌아갑니다.

### 3.2 레벨별 난이도

| 레벨 | FND 표시 | 숫자 표시 속도 |
|:---:|:---:|:---:|
| L.1 | `L--1` | 1000ms |
| L.2 | `L--2` | 600ms |
| L.3 | `L--3` | 300ms |

### 3.3 라이프 시스템

- 라이프는 **3개 고정**으로 시작합니다.
- 잔여 라이프 수는 **외부 LED 3개**로 표시합니다.
  - 라이프 3개: LED 3개 모두 ON
  - 라이프 2개: LED 2개 ON
  - 라이프 1개: LED 1개 ON
  - 라이프 0개: 게임 오버
- 틀렸을 때: 라이프 1 감소 → FND에 `L--x` 표시 (1초) → 같은 라운드 시퀀스 **재표시** → 재입력

### 3.4 점수 계산

```
최종 점수 = (클리어한 라운드 수 × 10) + (잔여 라이프 수 × 5)
```

예) 8라운드 클리어, 잔여 라이프 2개 → 80 + 10 = **90점**

### 3.5 게임 종료 조건

| 조건 | 처리 |
|---|---|
| 라이프 0개 | 게임 오버 → 라운드 표시 → 점수 표시 → 레벨 선택 복귀 |
| 16라운드 클리어 | `donE` 표시 → 점수 표시 → 레벨 선택 복귀 |

## 4. FND 표시 목록

| 상황 | FND 표시 | 표시 시간 |
|---|:---:|:---:|
| 레벨 선택 대기 | `L--1` / `L--2` / `L--3` | 키 입력 전까지 |
| 시퀀스 표시 중 | 숫자 1개씩 (`---5` 등) | 레벨별 속도 |
| 숫자 입력 대기 | `----` | 입력 전까지 |
| 숫자 입력 에코 | 입력한 숫자 (`---5` 등) | 0.3초 |
| 라운드 클리어 | `r--3` (라운드 번호) | 1초 |
| 라이프 감소 | `L--x` (x = 잔여 라이프) | 1초 |
| 게임 오버 | `OVER` | 1.5초 |
| 최종 라운드 표시 | `r--8` 등 | 2초 |
| 최종 점수 표시 | `0090` 등 | 2초 |
| 게임 클리어 | `donE` | 2초 |

## 5. 코드 설계 가이드

### 5.1 라이프 LED 핀 배치 (학생 자유 선택)

라이프 표시용 LED 3개의 핀 배치는 **학생이 직접 결정**합니다.  
PA, PB, PC는 이미 사용 중이므로 **PD 또는 PE 포트 사용을 권장**합니다.  
코드 상단의 `#define` 구역에 선택한 핀 번호를 반드시 기입하십시오.

```c
// 학생이 직접 수정하는 부분
#define LIFE_LED_PORT   PORTD
#define LIFE_LED_DDR    DDRD
#define LIFE_LED1_PIN   PD0   // 라이프 1번 LED
#define LIFE_LED2_PIN   PD1   // 라이프 2번 LED
#define LIFE_LED3_PIN   PD2   // 라이프 3번 LED
```

### 5.2 전역 변수 구조 (권장)

```c
uint8_t  state;              // 현재 상태
uint8_t  level;              // 선택된 레벨 (1, 2, 3)
uint16_t show_delay_ms;      // 레벨별 표시 속도

uint8_t  seq[16];            // 숫자 시퀀스 배열 (최대 16)
uint8_t  round_len;          // 현재 라운드 시퀀스 길이
uint8_t  show_idx;           // 현재 표시 중인 시퀀스 인덱스
uint8_t  input_idx;          // 현재 입력 중인 인덱스

uint8_t  life;               // 잔여 라이프
uint16_t score;              // 현재 점수
uint8_t  round;              // 현재 라운드 번호

uint16_t state_timer_ms;     // 상태 내 경과 시간 누적용
uint8_t  display_data[4];    // FND 버퍼
uint8_t  current_digit;      // 현재 표시 자리 (0~3)
```

### 5.3 의사 난수 생성

인터럽트를 사용하지 않으므로 루프 카운터 기반 의사 난수를 활용합니다.  
레벨 선택 대기 중 매 루프마다 `rand_seed`를 증가시켜 난수성을 확보합니다.

```c
uint16_t rand_seed = 1;

uint8_t pseudo_rand(void) {
    rand_seed = rand_seed * 1103515245 + 12345;
    return (rand_seed % 9) + 1;   // 1~9 반환
}

// while(1) 루프 내 레벨 선택 상태에서 매 사이클마다 실행
rand_seed++;
```

### 5.4 fnd_font 배열 확장

기본 제공 코드의 `fnd_font` 배열에 아래 항목을 추가해야 합니다.

| 인덱스 | 문자 | 세그먼트 값 (CA) | 용도 |
|:---:|:---:|:---:|---|
| 10 | `-` | `0xBF` | 하이픈 |
| 11 | ` ` | `0xFF` | 공백 |
| 12 | `L` | `0x87` | 레벨/라이프 표시 |
| 13 | `E` | `0x86` | donE |
| 14 | `d` | `0xA1` | donE |
| 15 | `r` | `0xAF` | 라운드 표시 |
| 16 | `n` | `0xAB` | donE |
| 17 | `V` | `0xC1` | OVER |

> 위 값은 Common Anode 기준이며, 실제 하드웨어에서 확인 후 필요 시 조정하십시오.

### 5.5 라이프 LED 제어 함수 예시

```c
void update_life_leds(uint8_t life) {
    // 모든 LED OFF
    LIFE_LED_PORT |= (1 << LIFE_LED1_PIN)
                  |  (1 << LIFE_LED2_PIN)
                  |  (1 << LIFE_LED3_PIN);
    // 잔여 라이프만큼 ON (Active Low 기준)
    if (life >= 1) LIFE_LED_PORT &= ~(1 << LIFE_LED1_PIN);
    if (life >= 2) LIFE_LED_PORT &= ~(1 << LIFE_LED2_PIN);
    if (life >= 3) LIFE_LED_PORT &= ~(1 << LIFE_LED3_PIN);
}
```

> LED 방식이 Active High인 경우 ON/OFF 로직을 반전하여 사용하십시오.
