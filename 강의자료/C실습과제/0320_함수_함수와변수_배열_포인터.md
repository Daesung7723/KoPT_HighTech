### [문제 1-1] 택배 요금 계산기

무게(kg)를 입력받아 택배 요금을 반환하는 함수 `calc_delivery()`를 작성하시오.

**[요금 기준]**
| 무게 | 요금 |
|------|------|
| 3kg 이하 | 3,500원 |
| 5kg 이하 | 5,000원 |
| 10kg 이하 | 7,500원 |
| 10kg 초과 | 10,000원 |

**[실행 예]**
```
무게 입력 (kg): 4
택배 요금: 5,000원
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

int calc_delivery(int weight) {
    if (weight <= 3)  return 3500;
    else if (weight <= 5)  return 5000;
    else if (weight <= 10) return 7500;
    else return 10000;
}

int main() {
    int weight;
    printf("무게 입력 (kg): ");
    scanf("%d", &weight);
    printf("택배 요금: %d원\n", calc_delivery(weight));
    return 0;
}
```

</details>

### [문제 2-1] 환율 변환기

금액(원)과 환율 종류를 입력받아 변환하는 함수들을 작성하시오.  
함수 원형을 `main()` 위에 반드시 선언할 것.

```c
double won_to_usd(int won);   // 1달러 = 1,350원
double won_to_jpy(int won);   // 1엔   = 9.2원
double won_to_eur(int won);   // 1유로 = 1,470원
```

**[실행 예]**
```
금액 입력 (원): 100000
변환 통화 선택 (1:달러  2:엔  3:유로): 1
74.07 USD
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

double won_to_usd(int won);
double won_to_jpy(int won);
double won_to_eur(int won);

double won_to_usd(int won) { return won / 1350.0; }
double won_to_jpy(int won) { return won / 9.2; }
double won_to_eur(int won) { return won / 1470.0; }

int main() {
    int won, choice;
    printf("금액 입력 (원): ");
    scanf("%d", &won);
    printf("변환 통화 선택 (1:달러  2:엔  3:유로): ");
    scanf("%d", &choice);

    if (choice == 1)      printf("%.2f USD\n", won_to_usd(won));
    else if (choice == 2) printf("%.2f JPY\n", won_to_jpy(won));
    else if (choice == 3) printf("%.2f EUR\n", won_to_eur(won));
    else printf("잘못된 선택입니다.\n");

    return 0;
}
```

### [문제 3-1] 자판기 재고 관리

음료 자판기를 시뮬레이션하는 프로그램을 작성하시오.

- 전역변수로 재고(`stock = 10`)와 총 판매금액(`total = 0`)을 관리
- `buy(int price)` 함수: 구매 시 재고 1 감소, 총액에 price 추가
- `show_status()` 함수: 현재 재고와 총 판매금액 출력
- 재고가 0이면 `"품절"` 출력 후 구매 불가

**[실행 예]**
```
[1] 구매(1,200원)  [2] 상태확인  [3] 종료
선택: 1
구매 완료! 남은 재고: 9개
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

int stock = 10;
int total = 0;

void buy(int price) {
    if (stock <= 0) {
        printf("품절입니다!\n");
        return;
    }
    stock--;
    total += price;
    printf("구매 완료! 남은 재고: %d개\n", stock);
}

void show_status() {
    printf("현재 재고: %d개 | 총 판매금액: %d원\n", stock, total);
}

int main() {
    int choice;
    while (1) {
        printf("\n[1] 구매(1,200원)  [2] 상태확인  [3] 종료\n");
        printf("선택: ");
        scanf("%d", &choice);
        if (choice == 1)      buy(1200);
        else if (choice == 2) show_status();
        else break;
    }
    return 0;
}
```

</details>

### [문제 4-1] 숫자 뒤집기 (재귀)

양의 정수를 입력받아 자릿수를 뒤집어 출력하는  
재귀 함수 `reverse_digit(int n)`을 작성하시오.  
> ⚠️ 문자열, 배열 사용 금지 — 순수 재귀만 사용

**[실행 예]**
```
숫자 입력: 12345
출력: 54321
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

void reverse_digit(int n) {
    if (n == 0) return;
    printf("%d", n % 10);
    reverse_digit(n / 10);
}

int main() {
    int n;
    printf("숫자 입력: ");
    scanf("%d", &n);
    printf("출력: ");
    reverse_digit(n);
    printf("\n");
    return 0;
}
```

</details>

## ✅ STEP 5 — 배열 기초

### [문제 5-1] 중복 없는 로또 번호 생성기

1~45 사이의 숫자 6개를 중복 없이 배열에 저장하고  
오름차순으로 정렬하여 출력하는 프로그램을 작성하시오.  
> ✅ `rand()`, `srand()`, `time()` 사용 허용

**[실행 예]**
```
이번 주 로또 번호: 3 14 22 31 38 44
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    int lotto[6], i, j, num, dup;
    srand(time(NULL));

    i = 0;
    while (i < 6) {
        num = rand() % 45 + 1;
        dup = 0;
        for (j = 0; j < i; j++) {
            if (lotto[j] == num) { dup = 1; break; }
        }
        if (!dup) lotto[i++] = num;
    }

    // 오름차순 정렬 (버블 정렬)
    for (i = 0; i < 5; i++)
        for (j = 0; j < 5 - i; j++)
            if (lotto[j] > lotto[j+1]) {
                int tmp = lotto[j];
                lotto[j] = lotto[j+1];
                lotto[j+1] = tmp;
            }

    printf("이번 주 로또 번호: ");
    for (i = 0; i < 6; i++) printf("%d ", lotto[i]);
    printf("\n");
    return 0;
}
```

</details>

### [문제 6-1] 성적 분포 막대그래프

학생 수 n과 점수를 입력받아 10점 단위 구간별 인원수를 `#`으로 출력하시오.

**[실행 예]**
```
학생 수: 10
점수 입력: 55 72 88 91 63 77 82 95 68 74

  0~ 59점 | #
 60~ 69점 | ##
 70~ 79점 | ###
 80~ 89점 | ##
 90~100점 | ##
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

int main() {
    int n, score, i, j;
    int bucket[10] = {0};  // 0~9: 0점대~90점대

    printf("학생 수: ");
    scanf("%d", &n);
    printf("점수 입력: ");
    for (i = 0; i < n; i++) {
        scanf("%d", &score);
        if (score == 100) bucket[9]++;
        else bucket[score / 10]++;
    }

    printf("\n");
    char *labels[] = {
        "  0~ 59점", " 60~ 69점", " 70~ 79점",
        " 80~ 89점", " 90~100점"
    };
    int merged[5];
    merged[0] = bucket[0]+bucket[1]+bucket[2]+bucket[3]+bucket[4]+bucket[5];
    merged[1] = bucket[6];
    merged[2] = bucket[7];
    merged[3] = bucket[8];
    merged[4] = bucket[9];

    for (i = 0; i < 5; i++) {
        printf("%s | ", labels[i]);
        for (j = 0; j < merged[i]; j++) printf("#");
        printf("\n");
    }
    return 0;
}
```

### [문제 6-2] 선택 정렬 + 순위 출력

5명의 이름(영문)과 점수를 입력받아  
점수 기준 내림차순으로 정렬 후 순위를 출력하시오.  
> ⚠️ 구조체 미사용 — 이름 배열과 점수 배열을 함께 정렬

**[실행 예]**
```
이름: Alice  점수: 88
이름: Bob    점수: 95
이름: Carol  점수: 72

[순위]
1위: Bob    95점
2위: Alice  88점
3위: Carol  72점
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>
#include <string.h>

#define N 5

int main() {
    char names[N][20], tmp_name[20];
    int scores[N], tmp_score, i, j, max_idx;

    for (i = 0; i < N; i++) {
        printf("이름: ");
        scanf("%s", names[i]);
        printf("점수: ");
        scanf("%d", &scores[i]);
    }

    // 선택 정렬 (내림차순)
    for (i = 0; i < N - 1; i++) {
        max_idx = i;
        for (j = i + 1; j < N; j++)
            if (scores[j] > scores[max_idx]) max_idx = j;
        // swap score
        tmp_score = scores[i];
        scores[i] = scores[max_idx];
        scores[max_idx] = tmp_score;
        // swap name
        strcpy(tmp_name, names[i]);
        strcpy(names[i], names[max_idx]);
        strcpy(names[max_idx], tmp_name);
    }

    printf("\n[순위]\n");
    for (i = 0; i < N; i++)
        printf("%d위: %-10s %d점\n", i + 1, names[i], scores[i]);

    return 0;
}
```

## ✅ STEP 7 — 포인터 기초

### [문제 7-1] 포인터로 온도 변환

섭씨(`celsius`) 값을 포인터로 받아 화씨와 켈빈으로 변환하는 함수를 작성하시오.  
> ⚠️ 반환값 없이 포인터 매개변수로 결과를 전달할 것

```c
void convert_temp(double *c, double *f, double *k);
```

**[실행 예]**
```
섭씨 입력: 100
화씨: 212.0℉
켈빈: 373.15K
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>

void convert_temp(double *c, double *f, double *k) {
    *f = (*c * 9.0 / 5.0) + 32;
    *k = *c + 273.15;
}

int main() {
    double c, f, k;
    printf("섭씨 입력: ");
    scanf("%lf", &c);
    convert_temp(&c, &f, &k);
    printf("화씨: %.1f℉\n", f);
    printf("켈빈: %.2fK\n", k);
    return 0;
}
```

</details>

## ✅ STEP 8 — 포인터와 배열

### [문제 8-1] ⭐ 최종 미니 프로젝트: 편의점 재고 관리 시스템

편의점 상품 5종의 이름, 가격, 재고를 배열로 관리하고  
포인터를 활용하여 아래 기능을 구현하시오.

**[구현 기능]**
1. 전체 재고 출력
2. 상품 구매 (재고 차감, 총 매출 누적)
3. 재고 0인 상품 자동 표시 (`[품절]`)
4. 총 매출액 출력
5. 재고 최소 상품 찾기 — 포인터 반환 함수 사용

```c
int* find_min_stock(int *stock, int n);  // 최소 재고 포인터 반환
```

**[실행 예]**
```
=== 편의점 재고 시스템 ===
[1] 삼각김밥  1,200원  재고:15개
[2] 컵라면    1,500원  재고: 8개
[3] 음료수    2,000원  재고:20개
[4] 과자      1,800원  재고: 3개  ← 재고 최소
[5] 도시락    4,500원  재고: 0개  [품절]
총 매출: 37,500원
```

<details>
<summary>✅ 정답 보기</summary>

```c
#include <stdio.h>
#include <string.h>

#define N 5

int* find_min_stock(int *stock, int n) {
    int *min = &stock[0];
    for (int i = 1; i < n; i++)
        if (*(stock + i) < *min) min = stock + i;
    return min;
}

int main() {
    char names[N][20] = {"삼각김밥","컵라면","음료수","과자","도시락"};
    int  price[N]     = {1200, 1500, 2000, 1800, 4500};
    int  stock[N]     = {15, 8, 20, 3, 0};
    int  total = 37500;  // 이미 판매된 누적 매출 예시
    int  choice, i;

    int *min_ptr = find_min_stock(stock, N);

    printf("\n=== 편의점 재고 시스템 ===\n");
    for (i = 0; i < N; i++) {
        printf("[%d] %-8s %5d원  재고:%2d개", i+1, names[i], price[i], stock[i]);
        if (stock + i == min_ptr && stock[i] > 0) printf("  ← 재고 최소");
        if (stock[i] == 0) printf("  [품절]");
        printf("\n");
    }
    printf("총 매출: %d원\n", total);

    // 구매 기능
    printf("\n구매할 상품 번호 (0=종료): ");
    while (scanf("%d", &choice) && choice != 0) {
        i = choice - 1;
        if (i < 0 || i >= N) { printf("잘못된 번호\n"); }
        else if (stock[i] == 0) { printf("[%s] 품절입니다!\n", names[i]); }
        else {
            stock[i]--;
            total += price[i];
            printf("[%s] 구매 완료! 재고: %d개 | 누적 매출: %d원\n",
                   names[i], stock[i], total);
        }
        printf("구매할 상품 번호 (0=종료): ");
    }
    return 0;
}
```

</details>
