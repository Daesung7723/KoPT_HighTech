# Stage ② — 요구사항 정의

## 4. 기능 요구사항 (Functional Requirements)

> 시스템이 **무엇을 해야 하는가**를 구체적으로 정의한다.
> 각 항목은 "~한다" 형식으로 단 하나의 동작만 포함하도록 작성한다.
> Stage ①의 기능 목록표를 기반으로 확장하여 작성한다.

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-01 | | 높음 / 중간 / 낮음 |
| FR-02 | | 높음 / 중간 / 낮음 |
| FR-03 | | 높음 / 중간 / 낮음 |
| FR-04 | | 높음 / 중간 / 낮음 |
| FR-05 | | 높음 / 중간 / 낮음 |

**작성 예시**:
- FR-01: 온도 센서 값을 1초마다 측정한다. (높음)
- FR-02: 온도가 30°C 이상이면 팬을 동작시킨다. (높음)
- FR-03: 현재 온도를 LCD에 표시한다. (높음)
- FR-04: 버튼 입력으로 기준 온도를 ±1°C씩 변경할 수 있다. (중간)
- FR-05: 센서 오류 발생 시 LED를 빠르게 점멸한다. (낮음)
