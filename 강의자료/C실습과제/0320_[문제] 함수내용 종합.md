## 📋 과제 개요

컴퓨터가 **1~100 사이의 정수**를 하나 무작위로 선택하고, 사용자가 그 숫자를 맞추는 게임을 구현한다.  
**메뉴 기반 인터페이스**를 통해 게임 시작, 점수 확인, 종료 기능을 제공하며,  
종료를 선택하기 전까지 메뉴가 반복 표시된다.

## 🪜 단계별 구현 요구사항

### Step 1 — 기본 입출력 및 조건문

**구현할 기능:**

- `rand() % 100 + 1`로 1~100 사이의 난수 생성 (`srand`로 시드 초기화)
- 사용자로부터 정수를 입력받아 정답과 비교
- `if-else if-else`로 세 가지 메시지 출력
  - 입력값 > 정답 → `"너무 큽니다!"`
  - 입력값 < 정답 → `"너무 작습니다!"`
  - 입력값 == 정답 → `"정답입니다!"`
- `while` 또는 `do-while`로 정답을 맞출 때까지 반복 입력
- 정답 시 시도 횟수 출력

**힌트:**

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

srand((unsigned int)time(NULL));
int answer = rand() % 100 + 1;
```

**실행 예시:**

```
숫자를 입력하세요: 50
너무 큽니다!
숫자를 입력하세요: 25
너무 작습니다!
숫자를 입력하세요: 37
정답입니다! (시도 횟수: 3회)
```

---

### Step 2 — 메뉴 시스템 추가

**구현할 기능:**

- 프로그램 시작 시 아래 메뉴 출력
- `switch-case`로 메뉴 번호에 따라 동작 분기
- `while(1)` 루프로 3번(종료) 선택 전까지 메뉴 반복 출력
- 1~3 외의 입력 시 `"잘못된 선택입니다."` 출력 후 메뉴 재출력

**메뉴 형식:**

```
===== 숫자 맞추기 게임 =====
1. 게임 시작
2. 점수 확인
3. 종료
선택: 
```

---

### Step 3 — 사용자 함수 분리

**구현할 기능:**

아래 함수를 **반드시 모두 구현**하고 `main()`에서 호출하라.  
각 함수는 `main()` **위에 선언(prototype)** 하고 아래에 정의할 것.

```c
void printMenu();              /* 메뉴 출력 */
int  generateNumber();         /* 1~100 난수 생성 후 반환 */
int  playGame(int answer);     /* 게임 진행, 시도 횟수 반환 */
void printResult(int tries);   /* 결과 메시지 출력 */
```

**요구사항:**

- `main()`은 함수 호출로만 구성되어야 하며, 게임 로직이 직접 작성되면 안 됨
- 각 함수의 역할이 명확히 분리되어 있어야 함

---

### Step 4 — 변수의 범위 및 생존 시간

**구현할 기능:**

| 변수 | 종류 | 선언 위치 | 역할 |
|------|------|-----------|------|
| `totalGames` | `static` 지역 변수 | `playGame()` 함수 내부 | 총 게임 횟수 누적 |
| `bestScore` | 전역 변수 | 모든 함수 밖 (초기값 `999`) | 최소 시도 횟수(최고 기록) 저장 |

- 메뉴 **2번 "점수 확인"** 선택 시 `totalGames`와 `bestScore` 출력
- 파일 상단 주석에 `static` 변수와 전역 변수의 차이를 **2~3문장**으로 설명

**실행 예시 (점수 확인):**

```
===== 점수 확인 =====
총 게임 횟수: 3회
최고 기록 (최소 시도): 4회
```

> **핵심 질문:** `totalGames`를 `static`이 아닌 일반 지역 변수로 선언하면 어떻게 될까?

## 💡 개념 참고

### 변수의 종류 비교

```c
int globalVar = 0;          // 전역 변수: 프로그램 전체에서 접근 가능, 프로그램 종료 시까지 유지

void someFunction() {
    int localVar = 0;       // 지역 변수: 함수 내부에서만 접근, 함수 종료 시 소멸
    static int staticVar = 0; // static 지역 변수: 함수 내부에서만 접근, 프로그램 종료 시까지 유지
}
```

### 함수 prototype 예시

```c
#include <stdio.h>

/* 함수 선언 (prototype) */
int add(int a, int b);

int main() {
    printf("%d\n", add(3, 4));  /* 함수 호출 */
    return 0;
}

/* 함수 정의 */
int add(int a, int b) {
    return a + b;
}
```
