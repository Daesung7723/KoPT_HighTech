# Stage ⑤ — 펌웨어 구현

## 1. 코드 구조 설명서

> 구현 시작 전 파일 구조를 먼저 계획한다. 이후 실제 구현에 따라 업데이트한다.

### 1-1. 파일 구조

```
[학번]_[이름]_하이테크프로젝트/Phase3_코드/
├── main.c          ← 초기화 호출 + 메인 루프
├── config.h        ← F_CPU, 핀 번호, 임계값 상수 정의
├── [모듈명].c       ← 기능별 구현 파일
├── [모듈명].h       ← 헤더 파일
└── backup/         ← 날짜 기반 백업
```

### 1-2. 파일별 역할 정의

| 파일명 | 역할 | 포함할 함수 (예시) |
|--------|------|-------------------|
| `main.c` | 초기화 호출, 메인 루프 | `main()` |
| `config.h` | 상수·핀 번호 정의 | (함수 없음 — `#define`만) |
| | | |
| | | |
| | | |

### 1-3. 주요 함수 설명표

> 구현 전에 계획하고, 구현 후에 실제 내용으로 업데이트한다.

| 파일 | 함수명 | 반환형 | 매개변수 | 기능 설명 |
|------|--------|--------|----------|-----------|
| main.c | `main` | `int` | 없음 | 초기화 + 메인 루프 |
| | `init_system` | `void` | 없음 | 전체 주변기기 초기화 |

| | | | | |
| | | | | |
